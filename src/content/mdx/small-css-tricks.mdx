# Building Cleaner Layouts with Modern CSS

Creating a good interface involves more than choosing colours and fonts. A well-structured layout should be consistent, responsive, and easy to maintain.

Modern CSS provides several tools that make this easier without requiring complicated styling rules.

Here are five techniques worth understanding when building frontend applications.

## 1. Use Flexbox and Grid for layout

Flexbox and CSS Grid solve different layout problems.

Flexbox works particularly well when arranging elements in one direction, such as navigation links, buttons, or items inside a card.

```css
.navigation {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
}
```

CSS Grid is useful when working with rows and columns, such as project cards or dashboard layouts.

```css
.project-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1.5rem;
}
```

Choosing the right layout system makes your styles easier to understand and adapt.

## 2. Use `gap` for consistent spacing

A common approach to spacing elements is adding margins to individual children.

However, this can become difficult to maintain when the number of elements changes.

The `gap` property provides a cleaner alternative.

```css
.card-list {
  display: flex;
  flex-direction: column;
  gap: 1rem;
}
```

The browser automatically maintains consistent spacing between the children.

The same property works with CSS Grid:

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 1.5rem;
}
```

This keeps spacing rules on the parent instead of distributing them across multiple child elements.

## 3. Prefer `min-height` over fixed heights

Using a fixed height can cause problems when content becomes longer than expected.

For example:

```css
.hero {
  height: 600px;
}
```

This forces the section to remain 600 pixels tall, even when the content needs more room.

A more flexible approach is:

```css
.hero {
  min-height: 600px;
  padding: 4rem 1.5rem;
}
```

The section can grow when its content requires additional space.

For a page section that should fill the available viewport:

```css
main {
  min-height: calc(100vh - 5rem);
}
```

Here, `5rem` represents the assumed header height. Adjust it to match the actual layout.

## 4. Make layouts responsive

A layout that works on a desktop screen might become cramped on a mobile device.

CSS media queries allow you to adjust the number of columns based on available screen width.

```css
.project-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

@media (min-width: 768px) {
  .project-grid {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

@media (min-width: 1024px) {
  .project-grid {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}
```

This approach starts with a single column and progressively introduces more columns as the available space increases.

## 5. Write CSS that is easier to maintain

Good CSS should be understandable when you revisit it weeks or months later.

A few habits help:

- Use meaningful class names.
- Avoid unnecessary fixed dimensions.
- Reuse spacing and colour variables.
- Keep related layout rules together.
- Prefer simple selectors over deeply nested rules.

For example, CSS custom properties make shared values easier to update:

```css
:root {
  --spacing-md: 1rem;
  --spacing-lg: 1.5rem;
  --content-width: 72rem;
}

.container {
  width: min(100% - 2rem, var(--content-width));
  margin-inline: auto;
}
```

Changing a shared value updates every component that uses it.

## Final thoughts

Clean layouts are not necessarily the ones with the most CSS. They are the ones built with clear decisions and reusable patterns.

Flexbox, Grid, `gap`, flexible heights, and responsive breakpoints provide a solid foundation for building interfaces that work across different screen sizes.

The goal is to make layouts easier to build today and easier to maintain tomorrow.
